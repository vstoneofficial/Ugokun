# うごくん CADデータ

うごくんのアタッチメントと、アタッチメントを取り付ける本体側の部品のSTEPデータです。用途に合わせて改変し、自由にアタッチメントを作成できます。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `6004_table.stp` | 本体側の部品（アタッチメントを取り付けるステージ台） |
| `petbottle/bottle_attachment.stp` | ペットボトル用アタッチメント（製品に付属しているものと同じ形状） |
| `smartphone/smartphone_stand_v2_asm.stp` | スマートフォンスタンド（組立品。下の3部品をまとめたもの） |
| `smartphone/stand_base_v2.stp` | スマートフォンスタンドのベース（ステージ台に取り付ける部分） |
| `smartphone/smartphone_stand_1.stp` | スマートフォンスタンドの部品1 |
| `smartphone/smartphone_stand_2.stp` | スマートフォンスタンドの部品2 |

単位はすべてmmです。

## アタッチメントを自作するときの注意

- 取り付け部（ステージ台の穴にはめ込み、横にスライドしてロックする部分）の形状は変えないでください。
- アタッチメントと載せる物の合計は、500 g以下を目安にしてください。
- 重心がステージ台の中心から大きくずれる物や、背の高い物は避けてください。
- ステージ台は左右に±150°回転し、上下に35 mm動きます。周囲の物や本体に当たらない大きさにしてください。

取り付け方は、うごくん取扱説明書の「3.4 アタッチメントの使い方」を参照してください。

## 本体側の部品（ステージ台）を改造するときの注意

- 本体側の部品を交換するには、うごくんの分解が必要です。分解・改造によって生じた故障や損害は、保証の対象外です。
- サーボとの取り付け部の形状は変えないでください。
- 重くしたり大きくしたりすると、サーボの負荷が増え、動作範囲内で周囲に当たるおそれがあります。
